Computational Thinking

Computational thinking is a problem-solving process that involves breaking down complex problems into smaller, manageable parts, identifying patterns, abstracting details, and designing step-by-step algorithms to arrive at a solution.

Abstraction

Abstraction means removing unnecessary detail so that we can focus on the essentials. For example, when drawing a map of London Underground, we don’t show every building or street, only stations and connections.

Decomposition

Decomposition means breaking a problem into smaller sub-problems. For instance, developing an e-commerce website can be decomposed into: user interface, product catalog, payment system, and delivery tracking.

Data Modelling

Data modelling involves designing the structure and relationships of data. For example, in a school database: students, teachers, and classes are entities, with attributes such as name, ID, and subject.

Pattern Recognition

Pattern recognition is identifying similarities or trends. For example, recognizing that all even numbers are divisible by 2 is pattern recognition.

Algorithm Design

Algorithm design is creating a sequence of steps to solve a problem. For example, designing steps to sort a list of numbers.

Algorithm: Bubble Sort
1. Repeat until no swaps
2. Compare each pair of adjacent items
3. If out of order, swap them
4. Continue until list is sorted

Expressing Algorithms

Algorithms can be expressed using pseudocode or flowcharts.

Pseudocode Example

   OUTPUT i
NEXT i

Chapter 12: Variables, Assignments, and Logic

12.04 Variables

When we input data for a process, individual values need to be stored in memory. To work with these values, we give each memory location a name known as a variable. Think of variables as boxes with labels. The label is the identifier, and the box holds the value.

Variable: A storage location for a data value that has an identifier.

For example, in a number-guessing game, the variable NumberOfGuesses may track how many guesses a player has made, while ThisPlayer might store the player’s name.

Figure 12.04 Variables

Variable identifiers should:

  • Contain only letters, digits, and underscores
  • Not contain spaces
  • Use meaningful names that describe their purpose
  • Often follow CamelCaps convention (e.g., NumberOfGuesses)

Practice Questions – Variables

Q1. Why should identifiers use meaningful names?

Meaningful names make the algorithm easier to read, understand, and maintain. They describe the purpose of the variable clearly.

Q2. Give two invalid variable names and explain why they are invalid.

Examples: 2total (starts with a digit), first name (contains a space). Both break naming rules.
