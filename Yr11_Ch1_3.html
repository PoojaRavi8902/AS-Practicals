1. Need for Compression

Why compression is essential

Compression reduces the amount of storage space and bandwidth required to store and transmit data.

  • Faster file transmission
  • Reduced storage costs
  • Efficient streaming
Exam phrase: Compression reduces file size while maintaining acceptable quality.

2. Lossy vs Lossless Compression

Comparison & exam definitions

Lossless compression

All original data can be perfectly reconstructed after decompression.

  • Used for text, programs
  • No data loss

Lossy compression

Some data is permanently removed to reduce file size.

  • Used for images, sound, video
  • Quality loss acceptable
Exam phrase: Lossy compression removes redundant or less noticeable data.

3. Run Length Encoding (RLE)

Lossless algorithm – very exam common

RLE replaces repeated data with a single value and a count.

Worked example

Original: AAAABBBCCDAA Encoded: 4A3B2C1D2A
Exam tip: RLE is efficient only when data has many repeated values.

4. Compression of Text, Images and Sound

Application-based explanations

Text compression

  • Uses lossless compression
  • Characters must be identical after decompression

Image compression

  • Lossy (JPEG) or lossless (PNG)
  • Removes unnecessary colour detail

Sound compression

  • Usually lossy (MP3)
  • Removes inaudible frequencies
Right Pane — Exam Practice
Structured

1. State two reasons why compression is needed. (2)

Reduces storage space and reduces transmission time.

2. Distinguish between lossy and lossless compression. (2)

Lossless compression allows perfect reconstruction, while lossy compression permanently removes some data.

3. Apply RLE to: BBBBBBBBAAC. (3)

8B2A1C

4. Explain why RLE is unsuitable for photographs. (2)

Photographs have frequent colour changes, so little repetition exists.

5. Identify suitable compression types for text, images, and sound. (3)

Text: lossless; Images: lossy or lossless; Sound: lossy.

6. Evaluate the effect of lossy compression on music streaming. (4)

Lossy compression reduces file size, enabling faster streaming and less bandwidth use, but slightly reduces sound quality.
