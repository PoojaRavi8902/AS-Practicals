13.01 Data Types

Every programming language needs to store and process data. A data type defines what kind of values a variable can hold and what operations can be performed on it. This section introduces the primitive and further data types used in pseudocode.

Primitive Data Types

INTEGER

Whole numbers (positive or negative, no decimals).

age ← 16
score ← -5

REAL

Numbers with decimal/fractional parts.

temperature ← 36.7
pi ← 3.14159

CHAR

A single character (letter, digit, or symbol).

middleInitial ← 'R'
symbol ← '#'

BOOLEAN

Logical values: TRUE or FALSE.

isEven ← TRUE
finished ← FALSE

Quick Check: What data type is price ← 250?

INTEGER (whole number, no decimal).

Further Data Types

STRING

A sequence of characters (letters, numbers, spaces, symbols).

name ← "Ravi Raju"
phone ← "0123456789"

DATE

Represents a calendar date.

dob ← 15/09/2005

Quick Check: Which data type would best store "12/09/2025"?

DATE (not STRING, because it represents a calendar date).
