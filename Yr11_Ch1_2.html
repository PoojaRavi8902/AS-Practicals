Chapter 1.2

1. Bitmap Representation

Resolution, colour depth, file size

What is a bitmap image?

A bitmap (raster) image is made up of a grid of tiny dots called pixels. Each pixel stores colour information. Examples include photographs and screenshots.

Resolution

Resolution is the number of pixels in an image, usually written as:

width × height Example: 1920 × 1080

Higher resolution → more detail → larger file size.

Colour depth

Colour depth is the number of bits used to store the colour of each pixel.

  • 1 bit → 2 colours (black & white)
  • 8 bits → 256 colours
  • 24 bits → 16.7 million colours (true colour)
Exam phrase: Increasing resolution or colour depth increases file size but improves image quality.

2. Bitmap Image File Size Calculation

Very high exam frequency

File size formula

File size (bits) = width × height × colour depth File size (bytes) = bits ÷ 8

Worked example

Image: 800 × 600 Colour depth: 24 bits Bits = 800 × 600 × 24 = 11,520,000 bits Bytes = 11,520,000 ÷ 8 = 1,440,000 bytes ≈ 1.44 MB
Exam tip: Always show units (bits / bytes / KB / MB).

3. Vector Graphics Representation

Objects, formulas, scalability

What are vector graphics?

Vector graphics store images using mathematical descriptions of shapes such as lines, curves, and polygons.

Key characteristics

  • Resolution independent (can scale without losing quality)
  • Small file sizes for simple images
  • Ideal for logos, diagrams, icons
Exam phrase: Vector graphics are resolution independent because they are defined mathematically.

4. Bitmap vs Vector Graphics

Comparison question favourite

Comparison

Bitmap: • Pixel-based • Loses quality when enlarged • Large file sizes • Best for photographs Vector: • Shape-based • Scales without quality loss • Smaller files • Best for logos & diagrams

5. Sound Sampling

Sample rate and resolution

Sampling

Sound sampling converts analogue sound waves into digital data by taking measurements at regular intervals.

Sample rate

Number of samples taken per second, measured in Hz.

CD quality = 44,100 Hz

Sample resolution

Number of bits used to store each sample.

  • 8-bit → lower accuracy
  • 16-bit → higher accuracy

6. Quality vs File Size Trade-offs

Evaluation-style answers

Trade-offs

  • Higher sample rate → better sound quality → larger file
  • Higher resolution → more accurate sound → larger file
  • Lower values → smaller files but loss of detail
Exam phrase: A balance must be chosen between acceptable quality and manageable file size.

7. Sound File Size Calculation

sample rate × resolution × channels × duration

Sound file size formula

File size (bits) = sample rate × resolution × channels × duration File size (bytes) = bits ÷ 8

Worked example (exam standard)

Sound clip length = 5 seconds Sample rate = 44,100 Hz Resolution = 16 bits Channels = 2 (stereo) Bits = 44,100 × 16 × 2 × 5 = 7,056,000 bits Bytes = 7,056,000 ÷ 8 = 882,000 bytes ≈ 0.88 MB
Exam tip: Always multiply all four factors. Channels = 2 for stereo, 1 for mono.
Right Pane — Student Exercises
Practice

1. Define resolution in bitmap images.

Resolution is the number of pixels in an image, usually expressed as width × height.

2. Calculate the file size (in bits) of a 640 × 480 image with 16-bit colour.

640 × 480 × 16 = 4,915,200 bits

3. State two advantages of vector graphics.

They can be scaled without losing quality and usually have smaller file sizes.

4. Give one suitable use of bitmap graphics and one of vector graphics.

Bitmap: photographs. Vector: logos.

5. Define sample rate.

The number of sound samples taken per second, measured in hertz.

6. State one effect of increasing sample resolution.

Improves sound accuracy but increases file size.

7. Explain why higher quality sound files are larger.

They use higher sample rates and/or higher resolution, which store more data per second.

8. Compare bitmap and vector graphics (two differences).

Bitmap images are pixel-based and lose quality when enlarged, while vector graphics are shape-based and scale without loss.

9. Identify two factors that affect bitmap image file size.

Resolution and colour depth.

10. Evaluate the trade-off between sound quality and file size.

Higher quality gives clearer sound but larger files, while lower quality reduces storage and bandwidth needs but loses detail.
